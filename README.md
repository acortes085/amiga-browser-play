# Amiga Browser Play

quiero una página web para jugar juegos de la amiga desde la web, vamos a empezar con 5 por ejemplo: face off, defender of castle, sensible soccer, agony, outrun europe. Cuando entres en un juego , que tengas la opcion de elegir cargar el juego desde el inicio, de un punto guardado o un punto que yo pueda elegir que sea ya con el juego cargado.  Ya preparare le archivo .Rom y los diferentes.adf
